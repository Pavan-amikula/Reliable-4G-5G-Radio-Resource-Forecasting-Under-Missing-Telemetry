What is the percentage?

It tells us how much of the available radio resource is being used. A reading of 20% means about one fifth is in use.

What is the range?

A lower and upper estimate of future usage. Ranges were adjusted using a separate set of past examples. They are not a guarantee.

What is this screen doing?

It replays saved measurements using already trained models. Later actual readings are only used for comparison. This is not a live network connection.
